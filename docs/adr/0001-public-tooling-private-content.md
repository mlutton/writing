# Keep writing tools and private material in separate repositories

The tools can be shared. Guides, personas, topics, drafts, and full article text belong in a separate private repo outside this tree. An ignored directory would only be protected from ordinary Git tracking. It could still be included when someone copies, archives, or syncs the directory.

The content guard checks changes locally and on push. Each published entry contains a short summary and a link to the canonical published article. The private repo retains the author’s full text.
