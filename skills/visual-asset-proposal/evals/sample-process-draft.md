# How a seed packet finds its place

The first year we held a seed swap, the welcome table filled up before
anyone had opened the doors. People brought envelopes with names like
“Grandma's beans” and “something orange.” Some had a variety written on
the front but no date. Two trays marked “flowers” looked identical until
someone noticed one was meant for seeds that needed a separate label.

The trouble started when people tried to do all the sorting at the welcome
table. The same volunteer was answering questions, collecting envelopes,
and trying to tell lavender from larkspur. When the queue backed up, the
next envelope went wherever there was space. By lunchtime nobody knew
whether the trays were sorted or still waiting.

This year we set up a short route for incoming packets. At the welcome
table we ask donors to write the name and, if they know it, when the seeds
were collected. The envelopes go into a single incoming basket. A volunteer
takes that basket to a separate sorting table when it starts to fill.

At the sorting table, we check the label and put each envelope into the
right category tray. If a label is incomplete, the envelope goes into a
question tray. Someone can check with the donor when there is time. If we
can fill in the missing detail, the envelope goes back through sorting. If
we can't identify the seeds, we set the packet aside.

The display table is only for envelopes that have cleared sorting. We put
a card in each tray so people can see which seeds belong together. When a
display tray empties, we replenish it from the matching category tray.
The welcome table can keep taking envelopes while people browse.

The route is the useful part. You can put the tables in a row if you have
the room, or around the edges of a small hall. The basket still has the
same destination. A volunteer joining halfway through can look at an
envelope and tell where it goes next.
