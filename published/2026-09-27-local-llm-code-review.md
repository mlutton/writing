A Qwen model, open-weight with 27 billion parameters (https://developers.google.com/machine-learning/glossary#parameter), runs on a single RTX 5090 in a gaming PC at home, behind a local inference server. It costs nothing per call, it never hits a subscription limit, and it answers in about ten seconds. Over several days, I tried to make it a code reviewer. It isn't one.
